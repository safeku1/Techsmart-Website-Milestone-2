Computer Shortcuts You Should Use

By TechSmart Admin · October 17, 2022

Here are some common computer shortcuts to help you save time and effort when using a Windows PC. Note that these shortcuts are different for Apple computers.

Here is a list of the basic shortcuts you can learn right now to help you complete simple tasks. For all of these, hold down Control and the corresponding letter at the same time.

Ctrl + C Copy
Ctrl + V Paste
Ctrl + Z Undo
Ctrl + X Cut
Ctrl + S Save

Write these down near your computer, and soon enough you will be using these shortcuts like a pro.

A few more shortcuts to try

Here are some less common shortcuts. If you are up for the challenge, try these out.

Ctrl + A Select all
Ctrl + F Find a word or phrase on a page or document
Ctrl + P Print
Ctrl + N Open a new window (in Microsoft Word, this opens a new document)

Why these shortcuts help

Why should you bother learning these? There are quite a few reasons to replace some mouse habits with keyboard shortcuts.

First is efficiency. You can increase your speed and productivity when you use your keyboard instead of using your mouse for everything. This helps you finish the job you are trying to accomplish much faster. You will not have to go in and manually highlight every word in a document. Instead, you can use Ctrl+A to select all those words, which is quicker and simpler.

Another reason to learn these shortcuts is to help prevent tendinitis. This is not a sure-fire way to protect your health, but using a mouse all day can cause inflammation of the wrists. Using these shortcuts can put less stress on your tendons.

There are several other benefits of using keyboard shortcuts. By starting to use these more than the mouse, you are making your time on a computer faster, simpler, and more beneficial for your health.
